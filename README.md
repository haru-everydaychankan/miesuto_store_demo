# ミエスト 店舗管理デモ

店舗スタッフ向けの在庫管理デモアプリです。

## 機能
- ダッシュボードで商品数・在庫あり・残りわずか・在庫なしを確認
- 在庫数を +/- ボタンで変更
- 在庫状態を自動判定（0個：在庫なし、1〜5個：残りわずか、6個以上：在庫あり）
- 商品の追加・編集・削除
- 商品名検索、カテゴリー・在庫状態で絞り込み
- 店舗名・住所・営業時間などの編集
- localStorageによる同じブラウザー内への保存

## GitHub Pagesで公開
1. GitHubで新しいリポジトリを作成（Publicがおすすめ）
2. `index.html` と `README.md` をリポジトリ直下にアップロード
3. Settings → Pages → Deploy from a branch
4. Branchを `main`、Folderを `/(root)` にしてSave

## 注意
これは発表・操作確認用の単独デモです。客側アプリやデータベースとは連携していません。入力データは利用中のブラウザーにのみ保存され、別端末・別ブラウザーとは共有されません。ログイン認証や実際の店舗データ連携も未実装です。
